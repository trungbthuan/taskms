1. Sơ đồ cấu trúc thư mục
task-management/
├── src/
│   ├── config/             # Cấu hình DB, Biến môi trường (env)
│   ├── controllers/        # Xử lý logic yêu cầu/phản hồi (Điều hướng)
│   ├── models/             # Định nghĩa cấu trúc dữ liệu (Schema)
│   ├── routes/             # Định nghĩa các đường dẫn API
│   ├── services/           # Xử lý logic nghiệp vụ (Tính toán, nhắc nhở)
│   ├── middlewares/        # Kiểm tra quyền (Sếp/Nhân viên), Validate dữ liệu
│   ├── utils/              # Các hàm dùng chung (định dạng ngày tháng, gửi mail)
│   └── app.js              # File khởi tạo ứng dụng chính
├── .env                    # Lưu mật khẩu, cổng, chuỗi kết nối DB
├── .gitignore              # Loại bỏ thư mục node_modules khi lưu trữ
├── package.json            # Quản lý thư viện
└── server.js               # File chạy server chính

2. Bước chuẩn bị tiếp theo. Cài đặt thư viện cần thiết
	npm init -y
	npm install express dotenv ejs
	npm install nodemon --save-dev
cài đặt driver cho PostgreSQL và Sequelize
	npm install sequelize pg pg-hstore

Cách chọn max-w phù hợp thực tế
Form đăng nhập / đăng ký  → max-w-sm  (384px)  — nhỏ gọn
Form 1 cột đơn giản       → max-w-md  (448px)
Form 2 cột / chi tiết     → max-w-2xl (672px)  ← bạn đang dùng
Trang dashboard / table   → max-w-5xl (1024px)
Full layout               → max-w-7xl (1280px)
